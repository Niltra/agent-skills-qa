Facturas para equipos

La aplicación permite emitir facturas, cobrar y conciliar el mes sin exportar nada a mano. El equipo de administración puede revisar los pagos desde un panel único, y el equipo de ventas consulta el estado de cada cliente cuando lo necesita con una búsqueda por nombre o por número de factura.

Los informes se generan cada mañana y se envían al correo que el usuario configure. Si un pago falla, la aplicación avisa en el panel y por correo, y deja el intento registrado para que se pueda revisar después con calma.
